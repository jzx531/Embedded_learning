## 2. 历史题考点与可靠答案

以下题目是对公开回忆的压缩转述，不是逐字原卷。

### 2.1 C 语言、C++ 与编译链接

#### 1. `static int c = 0;` 通常位于哪个段？

**答案**：具有静态存储期且初始化值为 0，通常放在 `.bss`；非零初始化通常放 `.data`；只读常量可能进入 `.rodata`。C 标准规定语义，不强制 ELF 段名，段归属是常见工具链实现。

#### 2. `int * const p = &a;` 哪部分不能修改？

**答案**：`p` 是常量指针，指针本身不能改指向，但 `*p` 可修改（前提是目标对象可写）。对比：

```c
const int *p1;       // 指向 const int，不能经 p1 改值，可改指向
int * const p2 = &a; // const 指针，可改值，不能改指向
const int * const p3 = &a; // 二者都不能经 p3 改
```

#### 3. 全局数组和局部未初始化数组的初值有什么区别？

**答案**：静态存储期对象默认零初始化；自动存储期局部数组未初始化时元素值不确定，读取未初始化值可能产生未定义行为。不要用打印结果推断语言规则。

#### 4. 为什么不能返回局部数组或局部变量的地址？

**答案**：函数返回后自动存储期结束，地址悬空。可改为调用者提供缓冲区、动态分配、返回值对象，或在明确并发约束下使用静态缓冲区。

#### 5. `volatile` 能保证什么？

**答案**：要求编译器按抽象机规则执行可观察的 volatile 访问，常用于 MMIO、ISR 共享标志等；它**不保证**原子性、互斥、跨核内存顺序或线程安全。并发同步应使用原子类型、锁和内存屏障。

#### 6. `char a[] = "Hello";` 的 `sizeof` 与 `strlen`？

**答案**：`sizeof(a) == 6`，包含结尾 `\0`；`strlen(a) == 5`。若作为函数形参 `char a[]`，会调整为指针，`sizeof(a)` 得到指针大小。

#### 7. 指针大小是多少？

**答案**：由 ABI 和目标架构决定，不能脱离环境回答。常见 32 位目标为 4 字节，64 位目标为 8 字节。使用 `sizeof(void *)` 实测。

#### 8. 结构体对齐如何计算？

```c
struct T {
    char a;
    double b;
    int c;
};
```

**答案**：若 `double` 对齐为 8、`int` 为 4，则常见布局为 `a` 1 字节 + 7 字节填充 + `b` 8 字节 + `c` 4 字节 + 4 字节尾填充，总计 24 字节。最终以目标 ABI、编译器选项和 `alignof` 为准。

#### 9. `#pragma pack(1)` 有什么风险？

**答案**：把成员最大对齐压到 1，减少填充，但可能产生非对齐访问，导致性能下降，某些架构甚至触发异常；还可能破坏 ABI。网络/文件格式应显式序列化，不要直接强转 packed struct。

#### 10. `unsigned char data[0]` 是标准 C 吗？

**答案**：零长数组是编译器扩展。标准 C99 的柔性数组成员写作 `unsigned char data[];`，且必须是结构体最后一个成员。分配大小为 `sizeof(struct header) + payload_len`。

#### 11. 位域可以直接用于协议或寄存器映射吗？

**答案**：位域的布局、分配方向和对齐含实现定义部分，跨编译器/协议不可靠。协议字段优先用整数、移位和掩码；MMIO 位域必须结合芯片头文件和工具链约定。

#### 12. 宏、`inline` 函数有什么区别？

**答案**：宏在预处理阶段做 token 替换，无类型检查，参数可能被重复求值；inline 函数有类型、作用域和正常求值语义。`inline` 只是优化相关提示，编译器仍可不内联。

#### 13. 编译流程是什么？

**答案**：预处理 -> 编译为汇编/中间表示 -> 汇编为目标文件 -> 链接生成映像。找不到外部符号通常在链接阶段报错；语法错误在编译阶段；宏展开问题在预处理后体现。

#### 14. 宏拼接与字符串化是什么？

```c
#define CAT(a, b) a##b
#define STR(x) #x
```

**答案**：`##` 拼接 token，`#` 把宏参数字符串化。若希望参数先展开再拼接，通常需要两层宏。

#### 15. `c = c++ % 5;` 的结果？

**答案**：不要计算结果。该表达式在 C/C++ 的相关规则下存在对同一标量对象未按要求排序的修改，属于未定义行为或不受保证的写法。拆成两条有明确顺序的语句。

#### 16. `x = -m++;` 如何结合？

**答案**：后缀 `++` 优先级高于一元负号，相当于 `x = -(m++);`。`x` 得到自增前的负值，随后 `m` 加 1。

#### 17. `func(a, b + c, (d, e));` 有几个实参？

**答案**：3 个。第三个是带括号的逗号表达式，其值为 `e`。参数求值顺序还要按具体 C/C++ 版本规则判断，不能依赖某个顺序产生副作用。

#### 18. `malloc` 与 `new` 的区别？

**答案**：`malloc` 分配原始字节并返回 `void *`，失败返回 `NULL`；`new` 分配对象存储并调用构造，通常失败抛异常。底层可能使用 `brk`、`mmap` 或分配器 arena，但这不是语言标准保证。

#### 19. `fork` 后内存立即复制两份吗？

**答案**：语义上父子进程拥有独立地址空间；现代系统一般用写时复制，物理页先共享，某一方写入时再复制。代码页等只读页可长期共享。

#### 20. 大小端如何检测？

```c
uint16_t x = 0x0102;
unsigned char *p = (unsigned char *)&x;
// p[0] == 0x02：小端；p[0] == 0x01：大端
```

协议传输应使用明确的字节序转换，不应把主机结构体直接发出去。

### 2.2 操作系统、FreeRTOS、中断与 Cache

#### 21. 进程三态及常见转换？

**答案**：运行、就绪、阻塞。运行 -> 就绪可由时间片耗尽/更高优先级抢占触发；运行 -> 阻塞由等待 I/O/同步触发；阻塞 -> 就绪由事件完成触发；就绪 -> 运行由调度器选择。阻塞任务不能直接变成运行，必须先就绪。

#### 22. FreeRTOS 中 Ready、Running、Blocked、Suspended 的差异？

**答案**：Blocked 等待带条件/超时的事件，到期或事件发生可自动回 Ready；Suspended 不参与调度，必须显式 resume。Ready -> Running 由调度；Running -> Ready 可被抢占或 yield。

#### 23. 二值信号量和互斥量的区别？

**答案**：互斥量有所有者语义，通常支持优先级继承，用于保护共享资源；二值信号量更适合事件通知，可由不同执行上下文 give/take。ISR 不能使用会阻塞的普通 API，应使用 `FromISR` 版本。

#### 24. 什么是优先级反转？

**答案**：高优先级任务等待低优先级任务持锁，同时中优先级任务持续抢占低优先级任务，使高优先级任务长时间无法运行。常见缓解：优先级继承、优先级天花板、缩短临界区和减少共享锁。

#### 25. 任务切换可能发生在什么时候？

**答案**：时间片耗尽、当前任务阻塞/延时/yield、更高优先级任务变为就绪、中断退出请求调度、任务删除等。具体取决于抢占、时间片和端口配置。

#### 26. 中断里能做什么？

**答案**：快速确认和清除中断源，读取/写入必要寄存器，把工作交给任务或下半部。不能阻塞，避免长循环、动态分配和复杂日志。RTOS API 必须使用 ISR 专用版本并处理是否需要切换上下文。

#### 27. Linux 中断上半部和下半部的原则？

**答案**：上半部处理必须立即完成的工作，尽量短；延后工作放 threaded IRQ、softirq、tasklet/workqueue 等机制。历史博客中“上半部一定关闭所有中断”的说法过于绝对，实际取决于内核版本、IRQ 类型和配置。

#### 28. 临界资源访问规则是什么？

**答案**：经典要求包括互斥、有限等待、空闲让进和让权等待等。工程上还要避免在持锁时阻塞、统一加锁顺序、限制临界区长度。

#### 29. 线程共享和独有的资源？

**答案**：同进程线程通常共享地址空间、代码、全局/堆、文件描述符；每个线程有自己的寄存器上下文、栈、线程局部存储和调度状态。

#### 30. `.text/.rodata/.data/.bss/heap/stack` 分别是什么？

**答案**：代码、只读常量、非零初始化静态对象、零初始化/未显式初始化静态对象、动态分配区域、调用帧/局部自动对象。嵌入式启动代码会把 `.data` 从 Flash 拷贝到 RAM，并清零 `.bss`。

#### 31. 什么是系统抖动 thrashing？

**答案**：工作集超过可用物理内存时，系统频繁换页，CPU 大量时间用于页面调入调出而非有效执行。增加并发进程可能使其更严重。

#### 32. FIFO 页面置换有什么问题？

**答案**：只按进入顺序淘汰，可能出现 Belady 异常，即增加页框反而增加缺页数。LRU 基于近期使用，但精确实现成本更高。

#### 33. Cache tag 位数怎样计算？

若物理地址 `A` 位、Cache 容量 `C` 字节、块大小 `B` 字节、`W` 路组相联：

```text
组数 S = C / (B * W)
offset 位 = log2(B)
index 位  = log2(S)
tag 位    = A - index - offset
```

还要考虑 valid、dirty、替换状态和地址使用物理/虚拟索引的具体实现。

#### 34. CPU Cache 与 DMA 为什么会不一致？

**答案**：CPU 可能只更新了 Cache，DMA 从 RAM 读到旧值；或 DMA 写了 RAM，CPU 仍读 Cache 旧副本。发送前 clean，接收后 invalidate，并保证 cache line 对齐、所有权和内存屏障正确。

#### 35. 流水线冒险有哪些？

**答案**：结构冒险、数据冒险、控制冒险。缓解方法包括资源复制、旁路/转发、stall、乱序执行和分支预测。

#### 36. CPU 的基本组成？

**答案**：控制器、运算器、寄存器组以及与存储系统的接口。程序计数器 PC 保存下一条或当前体系结构定义的指令地址；具体流水线语义依架构而异。

### 2.3 网络与通信

#### 37. IP 是面向连接还是无连接？

**答案**：IP 提供无连接、尽力而为的数据报服务，不保证可靠、顺序或无重复。

#### 38. 交换机端口和冲突域是什么关系？

**答案**：普通二层交换机每个端口通常形成独立冲突域；同一 VLAN 默认仍属一个广播域。全双工交换以太网不使用 CSMA/CD 处理冲突。

#### 39. VLAN 的作用？

**答案**：在二层逻辑划分广播域，改善隔离与管理；跨 VLAN 通信需要三层转发。802.1Q tag 包含 VLAN ID 等字段。

#### 40. 路由器和中继器位于哪层？

**答案**：路由器工作在网络层做 IP 转发；传统中继器工作在物理层，只再生信号。

#### 41. MAC 地址的基本知识？

**答案**：通常为 48 位；最低字节中的 I/G 位区分单播/组播，U/L 位区分全局/本地管理。MAC 只解决本地二层交付，跨网段要经路由。

#### 42. CRC 能纠错吗？

**答案**：CRC 主要用于检错，不直接纠错。发送方对比特多项式做模 2 除法附加余数，接收方检查余数。生成多项式决定可检测错误模式。

#### 43. 停等协议利用率怎样算？

一般模型：

```text
U = T_data / (T_data + 2*T_prop + T_ack + T_process)
```

历史回忆题写“数据帧和确认帧均 1000B、10kb/s、单向传播 200ms”。若 `B` 确实是字节：

```text
T_data = T_ack = 1000 * 8 / 10000 = 0.8 s
U = 0.8 / (0.8 + 0.4 + 0.8) = 0.4 = 40%
```

网上常见解答把 `1000B` 当 `1000bit`，这是单位错误。如果原题实际写的是 1000 bit，则利用率为 `0.1/(0.1+0.4+0.1)=1/6`。考试要先统一 bit/Byte。

#### 44. 8 kHz 无噪声信道、8 个离散电平，最大码率？

奈奎斯特公式：

```text
C = 2B log2(M) = 2 * 8000 * log2(8) = 48000 bit/s
```

额外给出的“每秒采样 24K 次”若不改变题目模型，是干扰信息。

#### 45. 子网划分函数需要哪些输入？

**答案**：IPv4 地址和前缀长度。掩码为前 `prefix` 位 1；网络地址 `ip & mask`；广播地址 `network | ~mask`。必须避免 `1u << 32` 等未定义移位，`/0` 和 `/32` 要单独处理。

#### 46. TCP 与 UDP 的核心区别？

**答案**：TCP 提供面向连接、可靠字节流、流控和拥塞控制；UDP 提供无连接数据报，保留消息边界，不保证可靠和顺序。实时性应用也必须自己处理丢包、拥塞与安全。

#### 47. Socket 的 `send`/`recv` 一次会完成全部数据吗？

**答案**：TCP 不保证一次完成全部字节，必须循环处理 short read/write；`recv == 0` 表示对端有序关闭。UDP 一次接收对应一个数据报，但缓冲区不足会截断。

### 2.4 数据结构与计算机组成

#### 48. 8 个顶点的简单无向图最多多少条边？

**答案**：`n(n-1)/2 = 8*7/2 = 28`。

#### 49. 长度 n 的单链表接到长度 m 的单链表之后，复杂度？

**答案**：如果只有第二条链表头指针，需要遍历到尾部，通常 `O(m)`；如果维护尾指针，则连接本身 `O(1)`。题目不给数据结构接口就不能唯一回答。

#### 50. 单链表按值查找复杂度？

**答案**：平均和最坏 `O(n)`，因为无法随机访问。

#### 51. 已知中序和后序怎样恢复前序？

**答案**：后序最后一个是根；在中序中定位根，划分左右子树；递归恢复。元素唯一时可用哈希表把定位降为 `O(1)`，整体 `O(n)`。

#### 52. 只知道前序和后序能唯一确定二叉树吗？

**答案**：一般不能；若每个内部节点都有两个孩子等额外约束，才可能唯一。单链形树的左右方向会产生歧义。

#### 53. 合法出栈序列如何判断？

**答案**：按入栈顺序模拟栈；每压入一个元素后尽量与目标出栈序列匹配。最终全部匹配则合法，时间 `O(n)`。

#### 54. 完全二叉树与满/完美二叉树区别？

**答案**：完全二叉树除最后一层外全满，最后一层从左连续；完美二叉树每层都满，节点数 `2^(h+1)-1`（根高度按 0）。中文“满二叉树”在不同教材中定义可能不同，要看题目约定。

#### 55. 16 位补码整数范围？

**答案**：有符号补码范围 `[-2^15, 2^15-1]`，即 `[-32768, 32767]`；无符号范围 `[0, 65535]`。

#### 56. 4 MB 内存按 16 位半字编址，需要多少地址？

**答案**：`4 MiB / 2 B = 2 Mi` 个可寻址单元，需要 21 位地址。历史文章写“寻址范围 2MB”容易把地址单元数量和字节容量混淆。

#### 57. 栈适合解决哪些典型问题？

**答案**：括号匹配、表达式求值、DFS、函数调用、单调栈。括号匹配遇左括号入栈，遇右括号检查栈顶类型，结束时栈必须为空。

### 2.5 音视频与数学专项

2023 页面回忆中出现过音视频和数学，音频/多媒体岗位应额外准备。

#### 58. H.264 为什么能压缩？

**答案**：利用帧内空间预测、帧间运动补偿去除冗余，再做变换、量化和熵编码。量化是主要有损环节；I/P/B 帧是常见图像类型描述，但编码结构还涉及 slice、NALU、参考列表等。

#### 59. DCT 的作用？

**答案**：把空间域信号变换到频率域，使能量集中在低频，便于量化和熵编码。DCT 本身可逆，信息损失主要来自量化和舍入。

#### 60. 常见图像增强方法？

**答案**：直方图均衡、对比度拉伸、Gamma、滤波锐化、去噪等。应根据噪声模型和任务指标选择，不能说某一种“总是最好”。

#### 61. 总谐波失真 THD 是什么？

**答案**：输出谐波分量 RMS 与基波 RMS 的比值，常写为：

```text
THD = sqrt(V2^2 + V3^2 + ... + Vn^2) / V1
```

通常用百分比或 dB 表示；THD+N 还包含噪声。

#### 62. 向量点积和矩阵乘法的维度条件？

**答案**：两个 n 维向量点积得到标量；`A(m×n) * B(n×p)` 得到 `m×p`。逐元素乘法不是矩阵乘法。

#### 63. 常见向量范数？

```text
L1 = sum |xi|
L2 = sqrt(sum xi^2)
L∞ = max |xi|
```

梯度指向函数局部上升最快方向，负梯度用于一阶下降。

## 3. 历史编程题模型与完整解法

历史题目经回忆后常缺少约束，以下给出可靠模型、算法和边界；若考试原题约束不同，应重新选择算法。

### 3.1 不使用数学库求 `m` 的 `n` 次根

对 `m >= 0, n > 0` 可用二分。`m < 0` 仅在 `n` 为奇数时有实根。乘法需要防溢出，可用 `long double` 并提前停止。

```cpp
#include <iostream>
#include <stdexcept>

static int compare_pow(long double x, int n, long double target) {
    long double value = 1.0L;
    for (int i = 0; i < n; ++i) {
        value *= x;
        if (value > target) return 1;
    }
    if (value < target) return -1;
    return 0;
}

long double nth_root(long double m, int n) {
    if (n <= 0) throw std::invalid_argument("n must be positive");
    if (m == 0) return 0;
    bool neg = m < 0;
    if (neg && n % 2 == 0) throw std::domain_error("no real root");
    long double target = neg ? -m : m;
    long double lo = 0, hi = target > 1 ? target : 1;
    for (int iter = 0; iter < 200; ++iter) {
        long double mid = (lo + hi) / 2;
        if (compare_pow(mid, n, target) < 0) lo = mid;
        else hi = mid;
    }
    long double ans = (lo + hi) / 2;
    return neg ? -ans : ans;
}
```

复杂度约 `O(n * log(精度范围))`。牛顿法更快，但需要处理初值、导数、除零和收敛。

### 3.2 第 n 个高度合成数

“高度合成数”通常指约数个数严格多于所有更小正整数的数。直接逐数分解很慢。候选数的质因数指数必须非增：

```text
x = 2^a1 * 3^a2 * 5^a3 * ...，且 a1 >= a2 >= a3 ...
约数数 d(x) = (a1+1)(a2+1)...
```

可 DFS 枚举非增指数，按数值排序后扫描纪录点。由于原回忆没有给 `n` 和数值上限，不能断言某个具体实现一定通过；面试时先问约束，再决定 `uint64_t`、大整数或剪枝上限。

### 3.3 Top-K 最大收益

历史回忆可抽象为：第 `i` 项升级收益 `gain[i] = population[i] * (target - level[i])`，最多选 `k` 项。

**解法**：计算所有非负收益，排序降序取前 `k`，复杂度 `O(n log n)`；若 `n` 很大、`k` 很小，用大小为 `k` 的小根堆，`O(n log k)`。

```cpp
long long max_gain(std::vector<long long> gain, int k) {
    std::sort(gain.begin(), gain.end(), std::greater<>());
    long long ans = 0;
    for (int i = 0; i < k && i < (int)gain.size(); ++i)
        if (gain[i] > 0) ans += gain[i];
    return ans;
}
```

### 3.4 带权不交叉连线

若每条线连接北岸 `x` 与南岸 `y`，权重为 `w`，选择不相交线使权重最大：

1. 按 `x` 升序排序；同 `x` 是否允许多选取决于题意，通常要按 `y` 降序防止错误同组转移；
2. 在 `y` 上做最大权重递增子序列；
3. `dp[i] = w[i] + max(dp[j])`，其中 `y[j] < y[i]`；
4. `O(n^2)` 基础版，或坐标压缩 + Fenwick/segment tree 做前缀最大值，`O(n log n)`。

### 3.5 原点锚定矩形的并面积

每个矩形是 `[0, x_i] × [0, y_i]`。并集边界是一个单调阶梯：

1. 按 `x` 升序排序；
2. 合并相同 `x`，保留最大 `y`；
3. 从右向左维护后缀最大高度；
4. 面积为相邻 `x` 区间宽度乘该区间可覆盖的最大高度。

```cpp
long long union_area(std::vector<std::pair<int,int>> p) {
    std::sort(p.begin(), p.end());
    std::vector<std::pair<int,int>> q;
    for (auto [x, y] : p) {
        if (!q.empty() && q.back().first == x) q.back().second = std::max(q.back().second, y);
        else q.push_back({x, y});
    }
    int h = 0;
    long long area = 0;
    for (int i = (int)q.size() - 1; i >= 0; --i) {
        h = std::max(h, q[i].second);
        int left = (i == 0 ? 0 : q[i - 1].first);
        area += 1LL * (q[i].first - left) * h;
    }
    return area;
}
```

### 3.6 只允许把元素移到最前/最后，最少操作排序

网上评论常把这题直接归为 `n - LIS`，但历史回忆给出的示例 `{5,3,1,2,4}` 已经能反驳该结论：LIS 可取 `{1,2,4}`，长度为 3，`n-LIS=2`；但值 `3` 无法通过“移到最前或最后”插入 `2` 与 `4` 之间，所以实际至少需要 3 次。

若数组元素互异，未移动元素必须同时满足：

1. 在原数组中的位置递增；
2. 在最终排序序列中的排名连续。

因此应在排序后的值序列中，寻找最长的连续排名区间，使这些值在原数组中的位置严格递增：

```cpp
int min_moves_to_ends(const std::vector<int>& a) {
    int n = (int)a.size();
    std::vector<std::pair<int, int>> value_pos;
    value_pos.reserve(n);
    for (int i = 0; i < n; ++i) value_pos.push_back({a[i], i});
    std::sort(value_pos.begin(), value_pos.end());

    for (int i = 1; i < n; ++i) {
        if (value_pos[i - 1].first == value_pos[i].first)
            throw std::invalid_argument("this version requires distinct values");
    }

    int best = n ? 1 : 0;
    int run = n ? 1 : 0;
    for (int rank = 1; rank < n; ++rank) {
        if (value_pos[rank - 1].second < value_pos[rank].second) ++run;
        else run = 1;
        best = std::max(best, run);
    }
    return n - best;
}
```

对 `{5,3,1,2,4}`，排序后排名 `1,2,3,4,5` 在原数组中的位置为 `2,3,1,4,0`，最长位置递增的连续排名段长度为 2，因此答案 `5-2=3`。

若数组允许重复，必须先明确稳定排序和相等元素的移动规则，不能简单替换为 LNDS。

### 3.7 摩尔投票

用于寻找出现次数严格大于 `n/2` 的候选：

```cpp
std::optional<int> majority(const std::vector<int>& a) {
    int cand = 0, count = 0;
    for (int x : a) {
        if (count == 0) cand = x;
        count += (x == cand) ? 1 : -1;
    }
    count = std::count(a.begin(), a.end(), cand);
    if (count > (int)a.size() / 2) return cand;
    return std::nullopt;
}
```

第一次扫描只给候选；若题目不保证多数元素存在，必须二次验证。

### 3.8 分数化简

```cpp
std::pair<long long,long long> reduce(long long a, long long b) {
    if (b == 0) throw std::invalid_argument("zero denominator");
    if (b < 0) { a = -a; b = -b; }
    long long g = std::gcd(std::llabs(a), b);
    return {a / g, b / g};
}
```

边界：分母不能为 0；负号统一放分子；`0/b` 化为 `0/1`。

### 3.9 分组检测题

公开回忆只保留了“n 个样本、m 个阳性、阴性组停止、阳性组继续分”的描述，没有组大小、是否已知阳性数、检测是否并行等关键约束，因此无法恢复唯一原题和答案。

应先澄清：

- 是求最坏、平均还是期望检测次数；
- 阳性样本位置是否均匀随机；
- 一次可混合多少样本；
- 阳性组如何分裂；
- 最后是否需要定位每个阳性样本。

不要背网上某个公式冒充原题答案。

## 4. 原创等价选择题题库（含答案）

### 4.1 C 与内存

1. **ISR 和主循环共享的 32 位标志，声明 `volatile` 后是否一定线程安全？**  
   **答**：不一定。可见访问不等于原子和同步；还要考虑目标架构访问宽度、竞态和内存顺序。

2. **`const uint8_t *p` 与 `uint8_t * const p` 的区别？**  
   **答**：前者不能经 `p` 改数据，后者不能改变 `p` 的指向。

3. **为什么 `memcpy(dst, src, n)` 不适合重叠区域？**  
   **答**：重叠时行为未定义，应使用 `memmove`。

4. **`sizeof(struct)` 为什么可能大于成员大小之和？**  
   **答**：成员内部填充和尾填充，用于满足对齐和数组元素对齐。

5. **`uint32_t x = 1u << 31` 是否安全？**  
   **答**：`1u` 为无符号且至少 32 位时可以；若写 `1 << 31`，有符号移位可能产生未定义行为。

6. **宏 `#define SQR(x) x*x` 有什么问题？**  
   **答**：缺括号且参数可能重复求值；至少写 `((x)*(x))`，但 `SQR(i++)` 仍错误，应使用 inline 函数。

7. **`char *p = "abc"; p[0]='A';` 是否合法？**  
   **答**：字符串字面量不可修改；C 中类型历史上不是 const，但修改仍未定义，C++ 直接不允许该转换。

8. **为什么嵌入式协议结构不宜直接 `send(fd, &s, sizeof s)`？**  
   **答**：存在对齐填充、大小端、类型宽度和 ABI 差异，应显式序列化。

9. **环形缓冲区如何区分满和空？**  
   **答**：保留一个空槽、维护计数，或使用单调递增读写索引；必须明确并发模型和内存序。

10. **函数内 `static` 变量何时初始化？**  
    **答**：具有静态存储期。C 中程序启动前完成静态初始化；C++ 局部 static 首次执行到声明时初始化，C++11 起保证线程安全初始化。

### 4.2 RTOS 与并发

11. **高优先级任务等待队列数据时，应该轮询还是阻塞？**  
    **答**：通常阻塞等待，避免占满 CPU；中断/生产者到来后唤醒。

12. **持有 mutex 时调用长时间阻塞 I/O 的风险？**  
    **答**：扩大临界区，导致优先级反转、延迟和死锁；应缩短锁范围或改变所有权模型。

13. **为什么 ISR 中不能调用普通 `xQueueSend`？**  
    **答**：普通 API 可能使用不适合 ISR 的临界区或阻塞；使用 `xQueueSendFromISR` 并按返回值触发切换。

14. **队列满时如何处理？**  
    **答**：根据语义选择阻塞、丢弃最新/最旧、覆盖、背压或扩大容量；必须记录丢包和高水位。

15. **死锁四条件？**  
    **答**：互斥、占有且等待、不可剥夺、循环等待。破坏任一条件可预防。

16. **任务通知与队列的差异？**  
    **答**：任务通知轻量、直接面向单个任务，适合事件/计数；队列能传递多条数据并支持多个生产者/消费者。

17. **tick 溢出如何安全比较超时？**  
    **答**：使用 RTOS 提供的延时/超时 API 或无符号差值比较，不直接比较绝对 tick 大小。

18. **双核系统仅关本核中断能保护跨核共享数据吗？**  
    **答**：不能，另一核仍可访问；需要跨核自旋锁/原子操作和正确内存屏障。

19. **看门狗应由谁喂？**  
    **答**：应证明关键任务都健康后统一喂，不能让任意卡死风险任务无条件喂狗。

20. **优先级越高越好吗？**  
    **答**：不是。优先级表达时限与依赖；滥用高优先级会饿死低优先级任务并放大抖动。

### 4.3 网络与无线系统

21. **TCP 粘包是协议错误吗？**  
    **答**：不是，TCP 是字节流，没有消息边界；应用层必须定义长度、分隔符或固定帧。

22. **UDP 校验和能保证应用数据绝对正确吗？**  
    **答**：不能绝对保证，且还不保证丢失、重复和顺序；关键协议需加入序号、超时、认证等。

23. **IPv4 `/24` 有多少地址？**  
    **答**：256 个地址；传统普通子网常有 254 个可分配主机地址，但 `/31`、`/32` 等有特殊语义。

24. **ARP 用来做什么？**  
    **答**：在 IPv4 本地链路把目标 IPv4 地址解析为链路层地址。跨网段时解析的是下一跳网关 MAC。

25. **Wi-Fi 断线重连状态机应避免什么？**  
    **答**：无限快速重试、并发启动多个连接、状态事件乱序、凭据泄漏。应做指数退避、单一状态所有者、超时和可观测日志。

26. **为什么网络回调中不宜直接做耗时业务？**  
    **答**：可能阻塞协议栈线程，导致丢包、超时和看门狗；应复制必要数据并投递工作队列。

27. **DNS 成功是否意味着 TCP 一定可连？**  
    **答**：不意味着。后续仍受路由、防火墙、端口监听、NAT 和服务状态影响。

28. **重传是否越多越可靠？**  
    **答**：过多重传会加剧拥塞和时延；应结合 RTT、退避、截止时间和幂等性。

### 4.4 数据结构与算法

29. **Top-K 用全排序还是堆？**  
    **答**：数据不大可全排序 `O(n log n)`；`k << n` 时用大小 k 小根堆 `O(n log k)`；整数范围有限也可计数。

30. **二分查找最容易错什么？**  
    **答**：区间定义不一致、循环条件、更新边界、重复元素和中点溢出。先明确 `[lo, hi)` 或 `[lo, hi]`。

31. **BFS 和 DFS 怎样选？**  
    **答**：无权最短路/层次用 BFS；路径枚举、拓扑结构或回溯常用 DFS。深图递归 DFS 要防栈溢出。

32. **哈希表查找一定是 `O(1)` 吗？**  
    **答**：平均期望 `O(1)`，最坏可达 `O(n)`；受哈希函数、负载因子、冲突策略和攻击输入影响。

33. **红黑树与哈希表怎样选？**  
    **答**：红黑树有序、最坏 `O(log n)`，支持范围查询；哈希表平均 `O(1)` 但无序、最坏退化。

34. **LIS 的 `lower_bound` 与 `upper_bound` 区别？**  
    **答**：严格递增用 `lower_bound`；非降序用 `upper_bound`。

35. **为什么“只允许移到首尾排序”不一定是 `n-LIS`？**  
    **答**：移到首尾无法把缺失值插入保留序列中间；未移动元素不仅要递增，还必须在目标有序序列中的排名连续。

36. **动态规划三要素？**  
    **答**：状态定义、转移方程、初始/边界；还要明确计算顺序和是否可压缩空间。

4. 给定帧长、ACK 长、带宽和传播延迟，计算停等协议利用率；
5. 画出 FreeRTOS 中高优先级任务被二值信号量/互斥量阻塞时的差异。

### 5.3 编程题 A：有序保留

给定一个由 `1..n` 构成的排列，每次可选一个元素移到最前或最后。求变为升序的最少操作次数。

**要求**：

- `1 <= n <= 2e5`；
- 元素互异且恰好为 `1..n`；
- 输出最少次数。

**答案**：构造 `pos[value]`，在 `value=1..n` 上寻找满足 `pos[value] < pos[value+1]` 的最长连续段，答案为 `n - best_run`，时间和空间均为 `O(n)`。

### 5.4 编程题 B：嵌入式事件队列

系统收到 `n` 个事件，每个事件有时间戳 `t`、优先级 `p`、处理收益 `v`。任意两个被处理事件的时间间隔必须至少为 `d`，最多处理 `k` 个，求最大收益。

**答案思路**：

1. 按时间排序；
2. 对每个 `i` 二分找到最后一个 `t[j] <= t[i]-d`；
3. `dp[i][c] = max(dp[i-1][c], dp[j][c-1] + v[i])`；
4. 时间 `O(nk log n)`，若 `k` 很大需进一步分析约束与优化。
